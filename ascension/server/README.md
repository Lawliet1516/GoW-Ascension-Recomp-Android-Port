# Server code for "Host a LAN server"

The launcher's *Host a LAN server* (Online page) runs the community server from this folder with the
launcher's own Python. Copy the `server/` folder of
[gowa-community-server](https://github.com/bc160201983/gowa-community-server) here (the `.py` files and
`admin_page.html`). Release zips already contain it.
